Supported Server Cores & Benchmarks

Deep technical comparison between all 3 server engines supported in Termux Script.

Server Core Edition Min RAM Needed Plugin/Mod Support Best For
PaperMC Java 1.5 GB Bukkit, Spigot, Paper Plugins High stability, lag fixing, small SMPs with friends.
Purpur Java (Fork) 2.0 GB All Paper plugins + Custom Configs Extreme customization (e.g., ridable mobs, performance tweaks).
PowerNukkitX Bedrock Native 1.0 GB JS / Java Nukkit Plugins Super lightweight Bedrock server with custom block/item support.

PaperMC Engine

Paper is designed to fix gameplay lag and exploit bugs. On mobile, Paper reduces tick rates of distant chunks and optimizes entity AI, allowing smooth 20 TPS performance even on mid-range phones.

Purpur Engine

Purpur expands Paper's features with deep configuration files (purpur.yml). Allows you to tweak mob spawning rates, command limits, and TPS thresholds directly from Termux text editor.

PowerNukkitX Engine

Built ground-up for Minecraft Bedrock (MCPE). PowerNukkitX executes natively without needing Java-to-Bedrock translation layers like Geyser, consuming minimal CPU cycles on Android ARM processors.
