Complete Technical Documentation

Termux par Android mobile se full-fledged Minecraft Server host karne ka comprehensive deep-dive guide.

1 Termux Environment & Package Configuration

Note: Google Play Store wala Termux version completely outdated hai aur usme build errors aayege. Always install Termux from F-Droid.

Step 1.1: System Repositories Update & Storage Permission

termux-setup-storage
pkg update -y && pkg upgrade -y

Step 1.2: Essential Dependencies Install Karen

OpenJDK 17/21 (Java Server chalane ke liye), Git (Repo clone ke liye), aur Wget/Curl required hain:

pkg install openjdk-17 git wget curl jq -y

2 Setup Project & Script Execution

Project repository ko Termux me clone karein aur execute permission grant karein:

git clone https://github.com/AdityaRoyall955/Minecraft-Ultimate-Turmux-server.git
cd Minecraft-Ultimate-Turmux-server
chmod +x *.sh

Script run karne par interactive menu open hoga jahan se aap Server Engine (Paper, Purpur, PowerNukkitX) choose kar sakte hain:

./start.sh

3 Server Configuration & Optimization (Deep Dive)

3.1 RAM Allocation Flags

Android Mobile me RAM Management bohot strict hoti hai. Isliye Java Virtual Machine (JVM) flags adjust karna zaroori hai:

java -Xms1024M -Xmx2048M -XX:+UseG1GC -jar paper.jar nogui
  • -Xms1024M: Initial RAM Allocation (1GB).
  • -Xmx2048M: Maximum RAM Limit (2GB recommended for 6GB RAM phones).
  • -XX:+UseG1GC: Garbage Collection optimization freeze/lag kam karne ke liye.

3.2 Cross-Play Setup (GeyserMC & Floodgate)

Agar aap Paper/Purpur Java Server bana rahe hain aur chahte hain ki Bedrock/PE players bhi connect ho sakein:

  1. Server ke /plugins folder me **Geyser-Spigot.jar** aur **Floodgate-Spigot.jar** daalein.
  2. Server restart karein. Floodgate se Bedrock players bina Java Account ke login kar sakte hain.
  3. Geyser config me UDP Port 19132 aur Java TCP Port 25565 link hota hai.

4 Public Connection & Port Forwarding

Mobile Data / Local Wi-Fi par public IP nahi hoti. Friends ko connect karwane ke liye tunnel tools use karein:

Option A: Playit.gg (Recommended)

Zero-configuration tunnel service jo Java & Bedrock dono UDP/TCP ports handle karti hai.

pkg install playit -y && playit

Option B: Ngrok TCP Tunnel

Fast connection but requires account authtoken setup inside Termux.

ngrok tcp 25565

5 Troubleshooting & Common Errors

Error: "Killed" or "Out of Memory (OOM)"

Reason: Android OS ne background Termux process ko memory limit exceed hone par kill kar diya.

Fix: Phone Settings me jaakar Termux ke liye Battery Optimization Disable karein aur startup RAM -Xmx value kam karein (e.g., 1.5GB).

Error: "Unable to access jarfile paper.jar"

Reason: Download incomplete tha ya jar file corrupt/missing directory me hai.

Fix: Script ke download section ko re-run karein ya manually jar file ko directory me place karein.
